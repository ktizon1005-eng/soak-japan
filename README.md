# Soak Japan

English guides to Japanese onsen and sento for foreign travellers (affiliate site).

- Write guides in `src/content/blog/*.md`. Set `draft: true` until every fact is checked against an official source; drafts are not built.
- Site name and author: `src/consts.ts`. Deploy path: `base` in `astro.config.mjs`.
- `npm run dev` to preview, `npm run build` to build. Pushing to `main` deploys to GitHub Pages.
